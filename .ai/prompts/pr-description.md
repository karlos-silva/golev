# PR Description Prompt

Gere uma descrição de PR seguindo o template do projeto:

1. Analise todos os arquivos modificados
2. Identifique o tipo de mudança (feature, fix, refactor, infra, schema)
3. Escreva um resumo claro e conciso
4. Preencha o checklist
5. Descreva o test plan
6. Se houver mudança de schema, destaque

Use o template em `.github/PULL_REQUEST_TEMPLATE.md`.
