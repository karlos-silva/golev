# Debug Help Prompt

Ajude a debugar o problema descrito:

1. Identifique a camada onde o erro ocorre (controller, service, DB, frontend)
2. Verifique se segue as convenções do projeto
3. Sugira passos de diagnóstico
4. Proponha solução que respeite a arquitetura (layered pragmático)
5. Se for erro de Drizzle, verifique schema, relations e queries
6. Se for erro de auth, verifique tokens, guards e permissions
